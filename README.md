# Modern Not Defteri 📝

Modern ve şık bir not defteri uygulaması. Avalonia UI kullanılarak cross-platform olarak geliştirilmiştir.

## ✨ Özellikler

- 🎨 **Modern Arayüz** - Fluent Design ile karanlık tema
- 📁 **Dosya İşlemleri** - Yeni dosya, Aç, Kaydet, Farklı Kaydet
- ✏️ **Metin Düzenleme** - Geri Al, Yinele
- ⌨️ **Klavye Kısayolları** - Hızlı erişim için kısayollar
- 🖥️ **Cross-Platform** - Windows, Linux, macOS desteği

## 🚀 Kurulum

### Gereksinimler

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Çalıştırma

```bash
cd ModernNotepad
dotnet build
dotnet run
```

## ⌨️ Klavye Kısayolları

| Kısayol | İşlev |
|---------|-------|
| `Ctrl+N` | Yeni Dosya |
| `Ctrl+O` | Dosya Aç |
| `Ctrl+S` | Kaydet |
| `Ctrl+Z` | Geri Al |
| `Ctrl+Y` | Yinele |
| `Ctrl+X` | Kes |
| `Ctrl+C` | Kopyala |
| `Ctrl+V` | Yapıştır |
